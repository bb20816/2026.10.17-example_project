# 🌡️ 서울 연평균 기온 분석 대시보드

Streamlit + pandas + Plotly를 이용한 서울 기온 데이터 시각화 웹앱입니다.  
`seoul_temperature.csv` 데이터를 바탕으로 **연도별 평균기온**, **5년 이동평균**, **연도 범위 슬라이더**, **선택 구간 통계**를 제공합니다.

---

## 📁 파일 구성

| 파일 | 설명 |
|---|---|
| `seoul_temperature_dashboard.py` | Streamlit 앱 전체 코드 |
| `requirements.txt` | 필수 패키지 목록 |
| `seoul_temperature.csv` | 데이터 파일 (코드와 같은 폴더에 배치) |

---

## ✨ 주요 기능

1. **연도별 평균기온 꺾은선 그래프**  
   연도별 `평균기온(℃)`을 꺾은선+마커로 표시합니다.

2. **5년 이동평균선 겹침 표시**  
   연평균기온 기준 5년 이동평균선을 점선으로 함께 표시합니다.

3. **사이드바 연도 범위 슬라이더**  
   사이드바에서 시작·종료 연도를 선택하면 선택 구간이 갱신됩니다.

4. **선택 구간 평균/최고/최저 기온 표시**  
   선택한 연도 범위에서 `평균기온`, `최고기온(평균)`, `최저기온(평균)`을 카드 형태로 보여줍니다.

---

## ⚙️ 데이터 처리 규칙

| 규칙 | 처리 방식 |
|---|---|
| 날짜 앞 탭 문자 | `날짜` 컬럼의 앞에 붙은 탭(`\t`)과 따옴표를 제거하고 `datetime`으로 변환 |
| 1950~1953년 결측치 | 평균 계산에서 제외하고, 화면 하단에 제외 사실을 명시 |
| 수치 변환 불가값 | `NaN`으로 처리 후 결측 행은 평균 계산에서 제외 |

---

## 🚀 실행 방법

```bash
# 1) 필수 패키지 설치
pip install -r requirements.txt

# 2) 앱 실행 (코드와 같은 폴더에서)
streamlit run seoul_temperature_dashboard.py
```

브라우저에서 `http://localhost:8501` 로 접속하면 사용할 수 있습니다.

---

## 📦 요구 사항

Python 3.9 이상, 다음 패키지가 필요합니다.

```txt
streamlit>=1.30.0
pandas>=2.2.0
plotly>=5.18.0
```

## 🔍 참고

- 앱 실행을 위해 `seoul_temperature.csv`가 `seoul_temperature_dashboard.py`와 **같은 폴더**에 있어야 합니다.
- 그래프는 연도별 전체 기간을 기본으로 표시하며, 슬라이더 범위 선택 시 선택 구간의 통계가 갱신됩니다.
